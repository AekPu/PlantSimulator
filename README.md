# Plant Simulator (ระบบจำลองโรงงานและสถานีอุตสาหกรรม)

ระบบจำลองโรงงานและสถานีต่างๆ สำหรับฝึกอบรมระบบควบคุมและการเชื่อมต่อข้อมูล
แต่ละโรงมีเครื่องจำลอง (ทำงานตามฟิสิกส์แบบง่าย) หน้าจอควบคุม และเสียงประกอบ
ค่าที่จำลองสามารถส่งออกไปยัง Modbus TCP, S7, Omron FINS/TCP หรือ MC Protocol เพื่อให้ Node-RED หรือ PLC อ่านได้

## เริ่มต้นใช้งาน

**ผู้ใช้ทั่วไป** ดับเบิลคลิก `start.bat` โปรแกรมจะเปิด Plant Studio ทันที (ครั้งแรกจะติดตั้งสภาพแวดล้อมให้อัตโนมัติ)

**ผู้พัฒนา** ดับเบิลคลิก `dev_menu.bat` เพื่อเปิดเมนูเต็ม (สร้างโรงใหม่ รันเครื่องจำลองแบบข้อความ เปิดหน้าจอโดยตรง ตรวจโครงการ)

ใน Plant Studio เลือกโรง แล้วกด **เปิดเครื่องจำลอง** (หรือ Enter) จากนั้นในหน้าต่างของโรง:
1. เลือกโปรโตคอลที่ต้องการในหน้าต่างเดียวกัน ระบบจะแสดงรายละเอียดและตัวอย่างที่อยู่ของ tag
2. กด **เริ่มจำลอง**
3. กด **F1** เพื่อดูรายการที่อยู่ของ tag ทั้งหมด

ปุ่มลัด: Enter เปิดโรง, ลูกศรขึ้นลงเลือกโรง, Delete ปิดโรง, M เปิดปิดเสียง, F5 รีเซ็ตโรง

## โครงสร้างโฟลเดอร์

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `app\` | Plant Studio หน้าหลัก และไอคอน |
| `core\` | โมดูลกลาง: โปรไฟล์ ตัวส่งออก (Modbus/S7/FINS/MC) โครงหน้าจอ เสียง และ log |
| `sim\` | เครื่องจำลองของแต่ละโรง |
| `gui\` | หน้าจอของแต่ละโรง |
| `plants\` | โปรไฟล์ของแต่ละโรง (ชื่อ tag ชนิดข้อมูล คำอธิบาย ฉาก) และ `registry.json` ทะเบียนโรง |
| `tools\` | ตัวช่วย: สร้างโรงใหม่, สร้างหน้าจอ, สร้าง flow Node-RED, ตรวจการเชื่อมต่อ, สรุปโครงการ |
| `tests\` | ชุดทดสอบอัตโนมัติ |
| `logs\` | บันทึกข้อผิดพลาดของโปรแกรม (หมุนเวียนอัตโนมัติ) |

## ตัวส่งออกข้อมูล (โปรโตคอล)

เลือกได้ทีละหนึ่งแบบในแต่ละหน้าจอ พอร์ตเริ่มต้นและรายละเอียดแสดงในหน้าเลือก

| โปรโตคอล | พอร์ตเริ่มต้น | หมายเหตุ |
|---|---|---|
| Modbus TCP | ตามโรง (5020 ถึง 5190) | ค่าทศนิยมใช้ Holding Register 2 ตัว (Big-endian) ค่าจริง/เท็จใช้ Coil |
| S7 (Siemens) | 1102 | ต้องติดตั้ง python-snap7 Rack 0 Slot 1 DB ค่าเริ่มต้น 1 |
| Omron FINS/TCP | 9600 | โหนดปลายทาง 1 ตำแหน่ง DM เริ่มต้น 100 |
| MC Protocol | 5007 | เฟรม 3E binary รุ่น Q series, iQ-R และ FX5U ตำแหน่ง D เริ่มต้น 100 |

ตารางที่อยู่ของทุก tag เปิดได้ที่หน้าจอด้วยปุ่ม F1

## การเพิ่มโรงใหม่

1. สร้างโรงด้วยคำสั่ง (ตัวอย่าง)
   ```powershell
   python tools\new_plant.py --key pump_house --name "อาคารสูบน้ำ" --type "สูบน้ำ" --port 5200 --scenes "ปกติ|ปั๊มขัดข้อง|ไฟดับ"
   ```
   คำสั่งนี้สร้างโปรไฟล์ เครื่องจำลองตัวอย่าง และหน้าจอพื้นฐาน พร้อมเพิ่มรายการในทะเบียน
2. แก้ชื่อ tag และคำอธิบายในไฟล์ `plants\<key>.json` ตามอุปกรณ์จริง
3. เขียนโมเดลในเครื่องจำลอง `sim\<key>_sim.py` แทนโมเดลทดลอง
4. สร้างหน้าจอจากเทมเพลต (หรือแก้ไฟล์ที่สร้างให้มีผังภาพเฉพาะ)
5. รัน `python -m pytest tests -q` เพื่อตรวจความสอดคล้อง

พอร์ตต้องไม่ซ้ำกับโรงอื่นในทะเบียน ชุดทดสอบจะแจ้งถ้าซ้ำ

## การทดสอบ

```powershell
python -m pytest tests -q
```

ชุดทดสอบครอบคลุม: ทะเบียนและโปรไฟล์ การจัดวางข้อมูลและการตอบกลับของทุกโปรโตคอล โมเดลของโรงที่เขียนใหม่ และหน้าจอของทุกโรง (ซ่อนหน้าต่างไว้ ไม่เด้งขึ้นมา)

ตรวจการเชื่อมต่อกับอุปกรณ์จริงหรือเครื่องจำลองด้วยเครื่องมือ `tools\protocol_check.py` ซึ่งอ่านทุก tag ตามที่อยู่ที่โปรเจกต์กำหนดแล้วแสดงค่า

## Node-RED

สร้าง flow ตั้งต้นของ S7 จากโปรไฟล์ได้ด้วย

```powershell
python tools\nodered_flow.py plants\booster_station.json --port 1102
```

แล้วนำไฟล์ที่ได้ใน `generated\` ไป Import ใน Node-RED

## เมื่อมีปัญหา

| อาการ | วิธีตรวจ |
|---|---|
| หน้าจอไม่เปิด หรือปิดไปเอง | ดูไฟล์ `logs\<ชื่อโปรแกรม>.log` |
| ไม่มีเสียง | เมนู เสียง > สถานะเสียง ตรวจว่าติดตั้ง numpy และ sounddevice แล้ว |
| S7 เชื่อมไม่ได้ | ตรวจว่าติดตั้ง python-snap7 และพอร์ตตรงกับที่แสดง |
| ค่าที่อ่านได้ผิดทั้งที่ที่อยู่ถูก | ตรวจลำดับคำของค่าทศนิยม (FINS และ MC ต่างจาก Modbus) |
| เปิดโรงซ้ำไม่ได้ | โรงนั้นยังทำงานอยู่ ปิดหน้าต่างเดิมก่อน |

## สถานะการทดสอบ

- ทดสอบอัตโนมัติผ่านทั้งหมดในสภาพแวดล้อมของการพัฒนา
- Modbus, FINS และ MC ทดสอบกับไคลเอนต์ที่เขียนขึ้นเอง
- S7, MC และ FINS กับ PLC จริง และ Node-RED ยังต้องทดสอบที่หน้างาน
